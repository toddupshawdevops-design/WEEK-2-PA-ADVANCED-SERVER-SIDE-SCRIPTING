## Project Overview
This project is a performance assessment demonstrating core Object-Oriented Programming (OOP) principles in PHP, including class definition, encapsulation (private properties), constructors, non-static accessor/formatting methods, and static utility methods.

The application dynamically renders a structured HTML table displaying personal name and address information for multiple `Person` objects.
